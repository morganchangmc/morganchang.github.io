# Morgan Chang portfolio

## Add a project
1. Upload the project's photos to `assets/img` (Add file > Upload files). Keep each under ~1 MB; JPG works best.
2. Open `_templates/new-project.md`, copy everything, then go to the `_projects` folder > Add file > Create new file.
3. Name it like `my-project.md`, paste the template, and replace the text and photo names.
4. Commit. The site rebuilds in about a minute.

## Edit or remove
- Change text: open the file in `_projects`, click the pencil icon, edit, commit.
- Change the order projects appear: change the `order:` number.
- Remove a project: delete its file in `_projects`.
- Contact details and tagline: `_config.yml`.

## Custom domain (later)
Buy a domain, then in the repo go to Settings > Pages > Custom domain. Add the DNS records GitHub lists at your registrar.
